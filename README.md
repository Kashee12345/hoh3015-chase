# Dr. Aggrawal's Chiro Chase

Practice game for **HOH 3015 · Chiropractic History, Theory, and Practice** (Vermont State University Online).
Race seven historical rivals (D.D. Palmer, A.T. Still, Clarence Gonstead, B.J. Palmer, Hippocrates, the AMA Committee
on Quackery, R.W. Stephenson) and the Major Premise across 365 questions built from the course companion text.

Play: https://kashee12345.github.io/hoh3015-chase/

Single self-contained HTML file. No login, no tracking; progress is stored only in your own browser.
